# FVG 儀表板統計開始日期

2026-09-29；baseline `51260c7`；分支 `codex/fvg-confluence-touch-option`。依使用者確認：按出場時間篩選，再取最近 N 筆。本次僅更動顯示統計，沒有變動交易條件、暖機、訊號狀態、下單、成交或成本預設。

## 使用與限制

在「輸入 → 儀表板」勾選「啟用統計開始日期」，設定「統計開始日期（按出場時間）」。預設關閉以保留原有統計，日期預填 2026-01-01 00:00 UTC+8，使用者自行選擇所需起點。

- 納入 `exit_time >= start`，包含恰好於起點出場；即使進場早於起點也納入。
- 筆數仍受「保留最近已出場交易圖形」的 N 限制，不是從起點之後無限累加。已有結束交易按出場時間排序，掃描最近 N 筆並篩日期，等同先篩日期再取最近 N 筆；不必重掃所有交易。
- 關閉開關即恢復舊統計。未平倉損益與目前狀態仍為當前值，不受已出場日期篩選影響。原交易圖形仍保留最近 N 筆，不受此統計日期篩選影響。
- 日期選擇器使用圖表時區；表格明示 UTC+8。新增實際資料開頭、最後已處理 15m 收盤時間、已處理 K 線數。這是載入資料範圍，並非畫面可見範圍或交易起訖。
- 起點早於載入資料時，表格提示「起點早於已載入資料」。日期 input 只能篩選現有結果，無法擴大 TV 歷史上限，也不會自動載入所選日期。
- 日期內零筆交易顯示「日期內無已出場交易」，勝率／PF／淨損益／R 顯示破折號，不能當成零報酬績效。
