# FVG 圖形跟隨實例交易方向

2026-09-29；baseline `73d57e5`；目前分支 `codex/fvg-confluence-touch-option`。本次為單一 Pine 顯示修正，不改交易契約；依專案小型非交易變更流程處理。

## 行為

「顯示 FVG 圖形（依此實例交易方向）」開啟時：

- 僅做多：只畫多方 1H／15m FVG、重疊區與 P 排序、形成點、F+、首次進區／失效／到期／關鍵 K 文字、關鍵 K 箭頭和棒色。
- 僅做空：只畫對稱的空方內容。
- 雙向單倉（舊版）：仍畫兩邊。
- 最近十筆失效矩形與明細只記所選方向的事件，因此保留的是最近十筆該方向事件；重疊區與 1H 本體失效仍分開記錄，同來源矩形去重。
- Data Window 的 FVG 邊界及觸碰／失效／過期／關鍵 K 計數也依所選方向；這些計數僅用於輸出。
- 1H 概覽套用相同方向；15m 細節仍不畫到 1H。

反向 FVG 偵測、veto、來源鎖定、生命週期及 key 狀態仍雙向計算。沒有以顯示 gate 包住策略狀態轉換。成交、名額、每來源一次、SL／TP、觸碰選項、預設值都保留。

多空雙實例可各自開啟 FVG 圖形，各畫自己的方向；若两份都開，整張圖自然同時有多空兩邊。交付時保留先前使用者設定：多方圖形 ON、空方 OFF，兩份模擬交易及其交易線／標籤仍開。驗證時暫開事件／失效表、暫隱藏多方，完成後均還原；未移除或新增任何圖表實例。
